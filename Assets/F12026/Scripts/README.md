# F12026 Unity Vehicle Core

This folder is the Unity-side replacement for the previous Three.js prototype.

Phase 1 includes:
- Rigidbody + four WheelColliders
- steering / throttle / brake
- 8-speed transmission
- ICE + MGU-K power
- ERS SoC consumption
- regenerative braking
- X/Z active aero
- aerodynamic downforce and drag
- wheel visual synchronization
- basic telemetry accessors

Next modules:
- Phase 2 Pacejka tire model
- suspension / camber / tire temperature
- advanced aero / ground effect
- AI racing line and overtaking
- race director / flags / VSC / safety car
- HUD / telemetry
- VFX and audio
