# F12026 Scenes

## Vehicle Test Scene

The editor menu:

F12026 > Build Vehicle Test Scene

creates:

- Assets/F12026/Scenes/F12026_VehicleTest.unity
- F12026_Car root with Rigidbody
- Four WheelColliders and wheel meshes
- Test track plane
- Directional light
- Chase camera
- Vehicle / input / telemetry / aero / power-unit components

This scene is a physics integration test, not the final visual F1 car.
