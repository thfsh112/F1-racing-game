# F1 Racing Game — Unity 6 Start

The repository is configured as a Unity 6 project.

## Version
Unity 6.2 / 6000.2.0f1.

Unity 6.2 is the 6000.2 release family. The project version is intentionally pinned so Unity Hub opens it with a known editor version.

## First run
Open the repository in Unity Hub, wait for packages/scripts to import, then use:

F12026 > Build Vehicle Test Scene

After the scene is generated:

Assets/F12026/Scenes/F12026_VehicleTest.unity

Press Play to test the car.

## Important
The GitHub Pages files are only the old browser prototype. The actual 3D simulation is the Unity project under Assets/F12026.

Do not expect the GitHub Pages URL to run the Unity C# project automatically; a Unity player build must be generated separately.
